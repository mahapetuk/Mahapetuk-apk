বিল খাতা — APK বানানোর নিয়ম (কম্পিউটারে কিছু install ছাড়াই)

1. github.com-এ একটা free account খুলুন, নতুন repository বানান (নাম: BillKhata)।
2. "uploading an existing file" চাপুন এবং এই ফোল্ডারের সব ফাইল/ফোল্ডার (.github সহ) upload করুন, তারপর Commit করুন।
3. repository-র "Actions" ট্যাবে যান। "Build APK" চলবে (৩-৫ মিনিট)।
4. শেষ হলে ওই run-এ ঢুকে নিচে "Artifacts" থেকে bill-khata-apk ডাউনলোড করুন।
5. ZIP খুললে app-debug.apk পাবেন। ফোনে নিয়ে install করুন ("Unknown sources" allow করতে হতে পারে)।

Android Studio থাকলে: ফোল্ডারটি open করে Build > Build APK(s)।
